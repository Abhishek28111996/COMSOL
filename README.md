# COMSOL Portfolio — GitHub Pages upload

This package is ready for the root of the public `Welcome1` repository.

1. Extract this ZIP on your computer.
2. In GitHub, open `Abhishek28111996/Welcome1` and choose **Add file → Upload files**.
3. Upload `index.html` and the complete `assets` folder (keep the folder structure).
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then choose **Save**.
7. Wait for GitHub Pages to finish deploying. The project site address should be `https://abhishek28111996.github.io/Welcome1/`.

The GitHub Pages address is a free GitHub subdomain. It replaces `chatgpt.site` in the URL but uses `github.io`.
